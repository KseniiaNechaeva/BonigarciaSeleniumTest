# UI test automation using Java and Selenium WebDriver
## Objective
The goal of this project is to develop an automated UI test using Selenium WebDriver to verify the functionality of the webpage https://bonigarcia.dev/selenium-webdriver-java/. The test will check the accessibility and correctness of links, page titles, and URLs.

## Task Requirements
Implement an automated UI test using Selenium WebDriver:
- Ensure that all links for Chapters 3-9 are accessible and open the correct pages
- Verify the page title and URL of the opened pages
- Confirm that each link belongs to the appropriate Chapter (e.g., "WebForm" should be in Chapter 3: WebDriver Fundamentals)

## Test Execution
Run the tests in parallel using JUnit 5
